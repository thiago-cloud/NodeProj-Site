# NodeProj

Status: Desenvolvedor ⚠️

Bem-vindo ao NodeProj! Este projeto é um frontend para um site de e-commerce focado em marketing digital e na criação de sites e aplicativos móveis. Utilizando tecnologias modernas como HTML, CSS, jQuery, Bootstrap e Google Fonts, NodeProj oferece uma experiência de usuário atraente e responsiva.

## Tecnologias Utilizadas

- **HTML:** Estruturação do conteúdo da página.
- **CSS:** Estilização e layout dos elementos.
- **jQuery:** Manipulação do DOM e interatividade.
- **Bootstrap CDN:** Framework CSS para design responsivo e componentes prontos para uso.
- **Google Fonts:** Tipografia personalizada para uma melhor estética.

## Funcionalidades

- **Design Responsivo:** Adaptado para diferentes tamanhos de tela e dispositivos.
- **Componentes Interativos:** Utilização de jQuery para funcionalidades dinâmicas.
- **Estilização Atraente:** Design moderno e profissional com Bootstrap e Google Fonts.
- **Facilidade de Uso:** Implementação simples com Live Server para desenvolvimento local.

## Estrutura do Repositório

O repositório está organizado da seguinte maneira:

- **/IMG:** Imagens utilizadas no site.
- **/css:** Contém os arquivos de estilos personalizados.
- **index.html:** Página principal do projeto.

## Execução do Projeto

1. Clone o Repositorio "git clone Linkgit"
2. Navegue até o diretório do projeto "cd NodeProj"
3. Abra o projeto em seu editor de código (recomendado o Visual Studio Code).
4. Inicie o Live Server Se você estiver usando o Visual Studio Code, você pode usar a extensão Live Server para visualizar o projeto em seu navegador. Basta clicar com o botão direito no arquivo index.html e selecionar "Open with Live Server". Caso esteja usando outro editor, você pode abrir o arquivo index.html diretamente em seu navegador.
